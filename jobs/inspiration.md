# Job: inspiration (daily)

Find at most 3 posts from people the user's audience or peers follow (PROFILE.md "Who counts", data/me/model.md). They must be worth a substantive reply from the user: new work, a real argument, or a question the user can answer from their own work. Skip announcements, promos, hiring posts and reruns of well-known takes. Zero is a normal day.

Read only, in your own browser tab, then close it. Write `drafts/engage/candidates-<date>.md`: author, link, 2 lines on what's new, and one line on what the user could add. Draft nothing. Queue one ask: "Pick one post to reply to". After the user picks, draft with `.claude/skills/engage/SKILL.md`. Set `last_run` for `inspiration`.
